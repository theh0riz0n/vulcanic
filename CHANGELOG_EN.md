# What's New in v1.7b

### 🚀 Dashboard Improvements
- **Automatic Schedule Switching**: The dashboard now automatically shows *tomorrow's* schedule after 16:00!
- **Weekend Greetings**: A new festive message appears on Saturdays and Sundays.

### 🛠️ Debugging & Tools
- **Debug Mode**: Enable it in Settings to see raw API IDs in Attendance and Grades.
- **Markdown Support**: The "What's New" modal now supports full **Markdown** formatting.

### 🐛 Bug Fixes
- Updated attendance mapping for IDs **24** (Presence) and **25** (Absence).
- Fixed UI font consistency by switching to **Outfit**.
